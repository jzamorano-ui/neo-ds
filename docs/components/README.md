# `docs/components/` — each component's spec

**Who it is for:** dev and design. **Ships**: yes — in the material, next to `packages/`.

One spec per component, `docs/components/<x>.md`: when it is used and when not, what it is confused
with, its anatomy with the master's measurements, its states, its accessibility and its API.

**The spec mirrors the Figma master**, which is the source. A difference between what this folder
says and what the master says is a defect of this folder, and it is fixed by measuring, not by editing.

And several exceptions that look like errors are a faithful mirror of Figma: they are noted with their
reason. **Read the why before "fixing" one.**
